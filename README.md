# Telegram-бот ролей

Бот объединяет участников Telegram-группы в независимые общие роли и позволяет вызвать выбранную роль через `@бот @код`.

Доступна **закрытая тестовая альфа**: создание и подтверждение роли, назначение через reply, вызовы в исходной теме, личный отказ от упоминаний, остановка очереди и удаление своего профиля. Данные хранятся в PostgreSQL; права, членство, дедупликация и неопределённые отправки проверяются сервером.

## Начать тестирование

На Windows нужны Python 3.12, Docker Desktop с Linux containers, отдельный бот и согласившаяся тестовая группа.

```powershell
cd D:\tgBotRole2026
.\start-test.ps1 -Discover
# Получите ID чата/пользователя и остановите обнаружение через Ctrl+C.
.\start-test.ps1
```

Токен вводится в скрытый запрос консоли и не сохраняется. Полная [инструкция запуска и команд](alpha/README.md) объясняет настройки прав и первый сценарий. [Протокол ALPHA-001](docs/testing/ALPHA-001.md) содержит выполненные проверки и оставшиеся ручные шаги.

Это промежуточный этап, а не публичный выпуск P0. Личные/скрытые роли, Mini App, платежи и остальные функции P1/P2 недоступны. Поведение настоящих клиентов и push-уведомления ещё проверяются в Telegram.

## Проверки

```powershell
.\start-test.ps1 -Check
```

Запускаются unit/integration сценарии с отдельной тестовой БД; токен не требуется. Зависимости альфы и probe изолированы. Точные дополнительные команды форматирования, lint и старых регрессий записаны в [статусе](docs/STATUS.md).
