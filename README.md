# Telegram-бот ролей

Проект Telegram-бота для объединения участников группового чата в независимые для каждого чата роли и адресного вызова роли. Выпуски разделены на закрытый пилот **P0**, публичный коммерческий продукт **P1** и последующие расширения **P2**.

## Текущая стадия

В репозитории пока нет реализации приложения, команд запуска, зависимостей или автоматических проверок. DOC-001 формирует документальную основу; наличие требований не означает готовность функций или прохождение приёмки. Проверенное состояние зафиксировано в [статусе](docs/STATUS.md).

## Запуск и проверки

Приложение ещё не реализовано, поэтому команды запуска и функциональных тестов отсутствуют. Для документальных изменений доступна стандартная проверка Git:

```bash
git diff --check
```

Не добавляйте в документацию предполагаемые команды запуска до появления соответствующей реализации.
