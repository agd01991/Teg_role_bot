# Telegram-бот ролей

Проект Telegram-бота для объединения участников группового чата в независимые для каждого чата роли и адресного вызова роли. Выпуски разделены на закрытый пилот **P0**, публичный коммерческий продукт **P1** и последующие расширения **P2**.

## Текущая стадия

Документальная основа проекта подготовлена, а для RES-001 добавлен изолированный запускаемый технический probe с автоматическими тестами. Это одноразовый инструмент исследования, не каркас приложения и не доказательство прохождения продуктовой приёмки. Актуальные задачи и проверенное состояние зафиксированы в [статусе](docs/STATUS.md).

## Запуск и проверки

Приложение ещё не реализовано. Технический probe, установка в чистый Python 3.12 venv, команды для Linux/macOS и Windows PowerShell, безопасное получение ID и ручной прогон описаны в [инструкции probe](experiments/telegram_probe/README.md). Протокол и честно незаполненные Telegram-наблюдения находятся в [RES-001](docs/research/RES-001.md).

Автоматические тесты probe после установки:

```bash
python -m unittest discover -s experiments/telegram_probe/tests -v
```
